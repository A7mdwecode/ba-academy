What Does a BA Do?
🔍

Analyze Data & Processes

BAs study how businesses work — what's broken, what works, and where opportunities are. They use data, not gut feelings.

🤝

Bridge Business & Tech

BAs translate between non-technical stakeholders and developers — writing requirements, creating mockups, keeping everyone aligned.

📊

Build Reports & Dashboards

Using Power BI, Tableau, or SQL, BAs visualize data so leadership can make fast, smart decisions.

🎯

Drive Business Decisions

Every query, report, and recommendation has a real business impact. BAs turn raw data into direction.

🎤 Interview Q&A
What is the difference between a functional and non-functional requirement?▼
Functional: what the system should DO (features). "Users can filter inventory by status." Non-functional: HOW it performs (speed, security). "Dashboard loads in 3 seconds." BAs document both in a BRD.
How do you handle stakeholder disagreements?▼
Listen to both sides fully. Shift focus to business objectives — "which option better serves the customer?" Use data where possible. If unresolved, escalate to the project sponsor. Always document decisions and rationale.
Walk me through how you'd analyze a business problem.▼
(1) Define the problem — current vs desired state. (2) Gather data — SQL, interviews, observation. (3) Identify root causes — 5 Whys or fishbone. (4) Evaluate solutions with stakeholders. (5) Document requirements. (6) Define KPIs to measure success.
Tell me about a project you worked on.▼
Use a real project you've built: "I designed and deployed a relational MySQL database on AWS RDS for [your project]. I built [X] tables covering [topics], wrote [N]+ SQL queries answering real business questions, and visualized the results in a live Power BI dashboard hosted on GitHub." Tip: use a personal, academic, or freelance project — real data makes the answer memorable.
What is Agile and how does a BA fit in?▼
Agile is iterative — work in 2-week sprints. BAs: write and refine user stories, join sprint planning and retrospectives, clarify requirements during sprints, accept completed stories against acceptance criteria.
Why do you want to be a BI Engineer at AWS?▼
Say: "Business Analytics is my major and AWS leads the cloud market. A cloud BI Engineer sits exactly where data and cloud meet — my target intersection. I built my first AWS project before applying — a live MySQL database on RDS — specifically to come in with real experience, not just a degree."
